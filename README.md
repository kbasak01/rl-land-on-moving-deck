# rl-land-on-moving-deck

Reinforcement-learning quadrotor landing on a Froude-scaled heaving ship deck in
gym-pybullet-drones, with deck motion from
[`deck-motion-forecast`](https://github.com/kbasak01/deck-motion-forecast).

**Simulation only.** Nothing in this repository is derived from, or validated against, real
ship-deck measurements or real flight.
